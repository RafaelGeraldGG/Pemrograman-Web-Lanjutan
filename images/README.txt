FOTO ANGGOTA KELOMPOK

Untuk mengganti foto, tim pengelola cukup menimpa file foto contoh di folder ini.
Gunakan nama file yang sama agar tidak perlu mengubah HTML:

anggota-01.jpg
anggota-02.jpg
anggota-03.jpg
anggota-04.jpg
anggota-05.jpg

Simpan foto sebagai JPG/JPEG dengan orientasi potret. Foto contoh dapat langsung
diganti dengan foto masing-masing anggota. Pengunjung website tidak memiliki
tombol atau kontrol untuk mengubah foto.
