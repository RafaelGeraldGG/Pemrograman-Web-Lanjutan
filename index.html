Silabus & Konsep Komputasi Web

Mengenal Mata Kuliah Pemrograman Web Lanjutan

Mata kuliah keahlian di FILKOM UKIM yang mempelajari rekayasa web modern secara menyeluruh: memahami apa saja yang dipelajari dalam pengembangan aplikasi web dan menelusuri bagaimana alur kerja dari web dari interaksi pengguna hingga pemrosesan server.

Materi Pokok Perkuliahan:
Topik Pembelajaran 01

Arsitektur Web Modern & Jamstack

Konsep Utama

Mempelajari transisi dari arsitektur web tradisional yang serba monolitik menuju arsitektur web terdistribusi. Mahasiswa belajar memisahkan antarmuka klien (*frontend*) dengan penyedia data (*backend API*), pemanfaatan Single Page Application (SPA), serta pengiriman data terstruktur berbasis JSON.

Decoupled Client-Server

Frontend fokus pada penyajian antarmuka responsif; server fokus pada pengolahan logika bisnis dan API.

Asynchronous Data Pipeline

Pengambilan data jaringan menggunakan Promises dan Async/Await tanpa memblokir thread antarmuka.

Eksperimen Interaktif: Fetch Asinkron HTTP 200 Ready
Latensi simulasi: 24ms · 1.4KB
Topik Pembelajaran 02

Reaktivitas & State Data

State Lab

Mempelajari teknik memperbarui tampilan layar secara instan ketika data berubah tanpa perlu reload halaman. Mencakup event listeners, manipulasi elemen Document Object Model (DOM), penyimpanan persisten browser melalui Web Storage API (`localStorage`), serta debouncing input.

Desain Sistem & Liquid UI

Topik Pembelajaran 04

Keamanan & Validasi Web

Security & QA

Memahami proteksi web terhadap celah keamanan umum seperti Cross-Site Scripting (XSS), SQL Injection, dan manipulasi data formulir. Mahasiswa diajarkan teknik sanitasi input, validasi dua arah (klien & server), serta pengoptimalan Core Web Vitals.

Siklus Kerja Web Menyeluruh

Bagaimana Alur Kerja dari Sebuah Web?

Dari saat pengguna berinteraksi di browser hingga server memproses basis data dan menyajikan respon balik.

1 Klien

Aksi Pengguna (Client Event)

Pengguna mengetik alamat URL, mengklik tautan, atau mengirim formulir di browser. Browser menangkap event dan menyiapkan paket permintaan.

2 Jaringan

Resolusi DNS & Handshake HTTPS

Domain (misal: ukim.ac.id) diubah menjadi alamat IP server melalui DNS Lookup. Koneksi aman TLS/HTTPS dibangun antara klien dan server.

3 Request

Pengiriman HTTP Request

Browser mengirimkan paket request berisi HTTP Method (GET, POST, PUT), Header, token otorisasi, dan body payload data ke web server.

4 Server

Routing & Logika Bisnis

Web Server (Apache/Nginx/Node.js) menerima request, mencocokkan rute (routing), mengeksekusi middleware, dan memanggil logika controller aplikasi.

5 Database

Query Basis Data & Response

Server berinteraksi dengan database (MySQL/PostgreSQL/NoSQL) untuk mengambil data, lalu mengemasnya menjadi respon HTTP (status 200 OK + JSON payload).

6 Rendering

DOM Hydration & Render Klien

Browser menerima data respon, mem-parse JSON, memperbarui elemen Document Object Model (DOM) secara reaktif, dan menampilkan hasil akhir ke layar.

Status Alur: Siap dijalankan. Klik tombol simulasi di atas untuk melihat alur kerja web langkah demi langkah.
